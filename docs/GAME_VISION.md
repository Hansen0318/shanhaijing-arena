# Game Vision

## One-line pitch
A mobile-landscape 3v3 semi-auto action RPG where anthropomorphic Shanhaijing heroes fight autonomously in a 2.5D arena while the player can instantly take over any allied character at critical moments.

## Core fantasy
Build a roster of distinctive Shanhaijing heroes, assemble a three-character team, watch them fight intelligently, and intervene at the right moment to change the battle.

## Design pillars
1. **Always alive** — characters move, attack, react, and use abilities even without input.
2. **Instant intervention** — player input immediately matters; no mode toggle is required.
3. **Readable chaos** — multiple characters, damage/heal numbers, status effects, and VFX remain understandable on a phone.
4. **Roster expression** — Type, Role, skills, passives, and synergies create different team builds.
5. **Character identity** — anthropomorphic designs preserve unmistakable Shanhaijing creature traits.

## Platform
- Mobile web first.
- Landscape orientation.
- Prototype optimized for touch controls and common phone widths.

## What this project is not
- Not a tower-defense sequel.
- Not a pure idle game.
- Not a pure auto-battler.
- Not a fully manual action RPG.
