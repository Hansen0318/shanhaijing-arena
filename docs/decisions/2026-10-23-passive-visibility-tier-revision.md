# P1 疾行 v2 — 玩家直接執行指令

玩家原文：「被動的文字不要出現，很怪，還有剛剛說的比例或增益要變更大，目前沒有感覺，還有跟隨T等級增加也要有，且要夠大的變化，確認就直接進行執行」。

此指令直接授權移除戰場被動文字並實作更強且隨T成長的疾行，不重新要求相同設計/計畫核准。依 brainstorming 的既有流程修訂路徑處理；使用者明確直接執行要求優先於技能預設停待核准。數值由本次實作選定，不冒稱玩家逐項核准新數值；仍須新版實機驗收。舊正式spec/plan及收據保留原bytes，本文件取代其相衝突的文字/數值需求。

T0/T1/T2/T3移速增益35%/50%/65%/80%，持續3秒，觸發起CD6秒。保留2秒一般實際走位1單位觸發、冷卻期間不累積、技能位移不計、既有AI/時鐘/清理契約。戰場不建立被動badge、HUD文字、倒數牌、連線；Collection保留完整說明。加速是實際一般移動，不更改角色比例、美術或技能位移速度。

共用資料新增完整四Tier倍率表及明確movementBonusCap。一般移速buff合計仍封頂15%，outgoing仍15%；只有具明確額度的movement狀態可取得較高上限。疾行額度95%，T3與既有10%移速可合計90%，到期各自回收，絕不使用角色ID判斷。所有狀態倍率仍驗證，較高額度須顯式宣告且不可超過100%。
