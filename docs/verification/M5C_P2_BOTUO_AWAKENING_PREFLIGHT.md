A proposed source-exact trim retains every RGBA pixel inside each extent and a 1-pixel source-exact transparent neighborhood; the opaque bounds are not used to rescale the character. Every original master/raw, the approved display derivatives, scripts, prompts, receipts and prior manifests stay unchanged.
