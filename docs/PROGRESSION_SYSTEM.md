# Progression System — Concept v1

> Character progression below remains future concept. M1 implements Campaign victory/unlock history only.

## M1 Campaign progression
Separate unlocked/cleared chapter/stage arrays derive from sequential victories. Defeat and Draw do not unlock. Cleared stages remain replayable. Versioned persistence is isolated from combat and replaceable; see CAMPAIGN_SYSTEM.md.


## Character acquisition
Primary concept:
Encounter character in story -> fight stronger versions -> clear Recruit Battle -> unlock character into roster.

## Tier progression
- Newly recruited character: T3.
- T3 -> T2: 5 fragments.
- T2 -> T1: 10 additional fragments.
- Total after recruitment: 15 fragments to reach T1.

## Tier philosophy
- T3: complete, fun, usable character with Basic/Heavy/Special/Awakening/Passive.
- T2: adds a meaningful mechanic or interaction.
- T1: completes/evolves the signature mechanic, especially Awakening/passive synergy.
- Do not make tiers only raw-stat multipliers.

## Fragment sources under consideration
- Character Challenge.
- Character Mastery/use missions.
- Chapter milestones.
- Universal fragments.
- Duplicate conversion if a future random-acquisition system exists.

## Level vs Tier
- Level: base stats.
- Tier: mechanic depth / character completion.
They remain separate systems.
