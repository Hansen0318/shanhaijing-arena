# Core Game Loop

## Long-term loop
Acquire character -> add to roster -> build 3-character team -> enter battle -> earn rewards/resources -> level/upgrade characters -> unlock more characters -> challenge later chapters.

## Battle loop
Team select -> versus/setup -> countdown -> 3v3 battle -> victory/defeat -> rewards -> return to progression.

## Campaign concept
- Chapters are story campaigns.
- Each chapter is planned around stages 1-1 through 1-5.
- Clearing a chapter unlocks the next chapter.
- Available chapters use full-color rectangular key art cards.
- Locked chapters use dark/grey cards with a central lock.
- Story is short and battle-focused; it should not repeatedly interrupt replay.

## Prototype note
M0 battle is player confirmed. M1 implements Chapter Select → Stage Select/Preview → START → existing Arena → Result → Retry / Exit / Next Preview → persistent unlock. No team-building UI or rewards/economy yet.
