# Type & Role System v1

## Types
- Power
- Speed
- Blast

## Counter triangle
- Power > Speed
- Speed > Blast
- Blast > Power

Initial prototype test modifier:
- advantage: +15% damage
- disadvantage: -15% damage
- same type: neutral

These values are tunable after playtesting.

## Roles
- Tank
- Attacker
- Support

Healer, Buffer, Debuffer, and Controller are Support subtypes in v1.

## Critical rule
**Type and Role are independent axes.**

Examples:
- Power / Tank
- Power / Attacker
- Power / Support
- Speed / Tank
- Speed / Attacker
- Speed / Support
- Blast / Tank
- Blast / Attacker
- Blast / Support

Type answers primarily "who do I counter / who counters me?"
Role answers "what job do I perform in the team?"
