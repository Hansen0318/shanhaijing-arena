# Shanhaijing Arena

Shanhaijing 3v3 semi-auto arena battle RPG.

## Project status
Current milestone: **Combat Prototype**.

This is a new project, separate from `shanhaijing-td`. It may reuse proven development workflow practices, but it does not reuse tower-defense gameplay architecture.

## Core concept
- Mobile landscape.
- 2.5D three-quarter arena.
- 3v3 real-time combat.
- All characters can fight autonomously.
- Player can select one allied character and intervene instantly.
- After 2.0 seconds without valid combat input, full AI decision-making resumes for that selected character.
- No AUTO/MANUAL UI mode indicator.
- Shanhaijing creatures are reimagined as anthropomorphic playable heroes.
